# 01-ukazka-objednavkoveho-formulara
Jednoduchý formulár na objednávku pre reklamné študio. Administrácia služieb nie je zahrnutá
Použité technológie: XAMPP, PHP, MySQL, Javascript. Je možné pozrieť na www-stranky.sk/reklamnestudio/objednavka.php
1. install xampp
2. vytvorit adresar objednavka
3. nakopirovanie suborov do adresara objednavka
4. spustit phpmyadmin
5. Nad databázou spustiť sql
6. Vytvorit adresar objednavka/admin
7. Vytvorit adresar objednavka/admin/mdbootstrap do ktoreho je potrebne stiahnut akutalnu verziu  mdbootstrap
8. Vytvoriť adrsár admin/prilohy do ktoreho sa budu zapisovat pridane prilohy
9. uprava suboru objednavka/config.php - nazov databazy a prihlasovacie udaje k databaze
